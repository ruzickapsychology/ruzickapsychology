# SEO-10-03 — Homepage credentials

## Decision: Archived after visual review

The initial implementation placed the existing About credential string in a new section beneath the hero. The user found this too sparse to justify a whole section. Removed the strip and its homepage-only About fetch/prop rather than moving redundant detail elsewhere.

Existing About credentials, article authorship and the footer license already provide qualification details. A separate homepage credential section has insufficient added value and interrupts the visual flow. No replacement styles or CMS changes were introduced.

The original audit recommendation remains in the tracker as history. This item is archived, not completed, and excluded from accepted-work progress. The superseded credential screenshot is removed from the PR; the updated transition screenshot shows the hero flowing directly into specialties.
