# SEO-15-02 — Remove contradictory billing-code advice

## Decision and scope

This is justified as a narrow correction. The published reimbursement guide
describes CPT 90837 as the practice's standard 60-minute individual session,
while the fee table advertises 50 minutes. We cannot determine the correct
billing code or session terms from that contradiction.

The migration removes the specific billing-code list from Step 2 and replaces
it with the existing seed fixture's neutral question about outpatient
psychotherapy benefits, referrals and authorization. In Step 4 it replaces the
CPT-specific allowed-amount question with the fixture's neutral question about
percentage reimbursement and submitting a superbill. It does not choose a
replacement code or change a practice policy.

## Implementation

- `scripts/lib/seo-ready-billing.ts` creates only two keyed reimbursement-guide
  body patches.
- `scripts/lib/seo-ready-billing-source.json` records the exact public source
  bodies fetched on October 17, 2026. Full structural comparison rejects changed
  wording, marks, annotations or missing/duplicate target items.
- The final Step 4 superbill paragraph remains identical, along with Steps 1
  and 3, headings, fee table, session lengths, insurance copy and all other fields.
- A repeated run returns no changes. A draft ID is rejected. The shared runner
  must enforce authenticated draft checks, the reviewed saved plan, revision
  guards and a backup before applying.
