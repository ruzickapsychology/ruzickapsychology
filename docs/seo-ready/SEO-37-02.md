# SEO-37-02 — Direct directions from Contact

## Decision and scope

Implement the scoped directions link. The existing map and address are useful,
but an ordinary link gives visitors a direct route to directions without using
the embedded map controls. This changes only this website, not a Google listing.
Parking and building-access claims remain outside this ticket: the current
published address is sufficient for a destination, not evidence of those facts.

## Implementation

- Add “Get directions in Google Maps” directly beneath the existing Contact map.
- Reuse `Stack gap="sm"` and `TextLink`; no new CSS, component, or visual system.
- Derive the map query and directions destination from one string containing
  the exact rendered CMS street address, locality, region, and postal code.
- Use the [documented Google Maps URL format](https://developers.google.com/maps/documentation/urls/get-started#directions):
  `https://www.google.com/maps/dir/?api=1&destination=…`, with an encoded address.
- Leave origin and travel mode to the visitor. The link opens in the current
  browsing context and adds no form data, user identifiers, or analytics event.

## Verification

Focused formatting, ESLint and component-contract checks passed. The integrated
production build and 105 unit tests passed before browser review.

Browser checks at 375px, 768px, and 1440px confirmed that the directions
destination exactly matches the embedded map query, Tab reaches the link with
a visible focus outline, and Enter navigates to its expected URL. Navigation
was intercepted after activation to avoid depending on Google's response.
No horizontal overflow appeared. Additional 390px and 1440px visual review
confirmed the link remains directly below the map.
