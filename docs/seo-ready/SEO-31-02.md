# SEO-31-02 — Footer license line

## Ask and decision

Expose the already-published psychologist license in the shared footer. Implemented because visitors can confirm the clinician's qualification on every public page without navigating to About. This is a usability/trust improvement, with no promised ranking gain.

The audit's exact proposed wording is not required. The footer uses the existing About credential group's `license` text verbatim rather than maintaining a second hardcoded credential claim or extracting a license number from prose. No additional Christina confirmation or CMS write is needed.

## Implementation

- The public site layout loads About and practice settings in parallel using the existing CMS data loaders.
- Nonempty license fields are trimmed and deduplicated, then passed as a typed `licenses` prop to the render-only shared footer.
- The footer places the license above copyright using existing `Text` detail/inverse typography and the existing information `Stack`.
- Missing About/license content renders no license line; there is no seed fallback or invented value.
- No CSS, new visual system, schema, query, or clinical copy changes.

## Validation

- Focused existing layout-composition suite: 3 tests passed.
- Prettier clean for both changed TSX files.
- Combined production build and desktop/mobile visual review are coordinated by the parent agent; the footer should show the same license text as About without overflow.

## Disposition

Implemented; awaiting combined verification before the coordinator marks Done. Screenshot target: shared footer on home at desktop and mobile widths. Existing CMS content remains the authority for the license text.
