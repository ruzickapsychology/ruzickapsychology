# SEO-12-02 — Name the doctoral degree and graduation year

## Decision and evidence

Implement the narrow factual improvement in the existing About education entry.
On 2026-10-17 the [practitioner-owned Psychology Today profile](https://www.psychologytoday.com/us/therapists/christina-ruzicka-rochester-ny/912736)
identified California School of Professional Psychology (CSPP), Psy.D., graduated 2020. The current published Sanity entry still said “Doctoral Degree”; its
institution detail already names CSPP at Alliant International University, San
Diego, CA. Retain that detail unchanged and replace only the title with
“Doctor of Psychology (Psy.D.), 2020”. No new section or visual style is needed.

## Implementation

- Seed fixture matches the intended degree/year so future intentional seeding
  does not regress it.
- `scripts/lib/seo-ready-degree.ts` accepts only the observed source title and
  institution, or the exact completed title. It patches one keyed title field,
  preserving the other credentials and all unrelated About fields.
- `scripts/migrate-ready-website-content.ts` composes the three narrow website
  content planners with the existing saved-plan comparison infrastructure.
  Preview, exact plan replay, revision guards, draft checks, exclusive backup,
  target identity and source revision checks are required. No broad reseed.

## Verification

Four focused degree tests cover narrow mutation, idempotency, changed source
rejection, and wrong-target/draft rejection. These and the eight existing plan
safeguard tests passed. The coordinator applied the reviewed narrow patch to the production CMS on
2026-10-17 with an exclusive backup. A fresh authenticated preview after apply
returned zero changes across all three target documents. Rendered About
verification is part of the coordinator’s integration checks.

### Completed browser verification

The production build displays the exact degree/year within the existing education list. Checked at 390px and 1440px without horizontal overflow. The integrated suite passed 105 unit tests and 112 browser tests (10 existing conditional skips).
